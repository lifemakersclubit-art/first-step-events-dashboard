# لوحة قيادة الإيفنتات · Hayat Makers Central Events Dashboard

لوحة تنفيذية عربية (RTL) لقياس **سرعة التسجيل، الإيقاع، الجودة، والجمهور** لكل إيفنت —
تعمل **بالكامل Offline** من `index.html`، مع خيار ربط **Google Sheet مباشر** عبر
Google Apps Script (ملف `Code.gs` واحد فقط).

---

## التشغيل السريع

```text
1) افتح index.html مباشرة (دبل كلك) — يشتغل Offline ببيانات تجريبية.
2) لا يحتاج Node ولا Build ولا سيرفر — كلها ملفات ثابتة.
```

- `CONFIG.DEMO_MODE = true` (افتراضيًا) → بيانات تجريبية مولّدة محليًا (بدون أي بيانات حقيقية).
- الوضع الليلي `SURFACE: "canvas"` (داكن) أو `"paper"` (نهاري) في `js/config.js`.

## ربط Google Sheet حقيقي (Optional API Mode)

### 1) إنشاء الـ Backend (ملف واحد فقط)

1. افتح شيت البيانات → **Extensions → Apps Script**.
2. احذف أي محتوى موجود، والصق محتوى `google-apps-script/Code.gs` كاملًا.
3. عدّل `CFG` في أول الملف إن لزم (اسم/رقم التبويب — الافتراضي `gid: 1436196095`).
4. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy → انسخ الرابط المنتهي بـ `/exec`.
5. جرّب من المحرر: شغّل `testConnection()` ثم `testPayload()` —
   `piiLeak` لازم يطلع `[]`.

### 2) توصيل الواجهة

في `js/config.js`:

```js
DEMO_MODE: false,
API_URL: "https://script.google.com/macros/s/XXXX/exec",
```

- الواجهة تجرّب `fetch` أولًا، وعند فشل الـ CORS تتحول **تلقائيًا لـ JSONP** (السيرفر يدعمه).
- آخر payload يُخزَّن في `localStorage` ويُستخدم عند انقطاع النت (TTL = `CACHE_TTL`).
- الواجهة لا تحمل أي أسرار إطلاقًا — الرابط عام والسيرفر يعيد سجلات بلا PII.

### 3) أفعال الـ API

| الرابط | الاستجابة |
|---|---|
| `?action=dashboard` | `{success, records[], meta, updatedAt}` |
| `?action=ping` | `{success, serverTime, version, sheet}` |
| `…&callback=fn` | نفس البيانات ملفوفة بـ `fn(...)` (JSONP) |

## الخصوصية (عقد صارم)

- **لا يغادر الشيت**: الاسم، الهاتف، الواتساب، البريد، الرقم القومي، Participant ID، QR.
- تُقرأ داخليًا في السيرفر فقط لإنتاج **أعلام جودة** منطقية:
  `hasPhone`، `invalidEmail`، `dupEmail`… (true/false فقط).
- الواجهة تعرض **أرقامًا وإحصاءات فقط** — لا سجلات فردية أبدًا.
- `sample-data/` بيانات **مصطنعة بالكامل**.

## تعريفات المقاييس

### شريط KPI (الرئيسية)
| المقياس | التعريف |
|---|---|
| إجمالي التسجيلات | عدد السجلات الصالحة (تاريخ صالح) منذ بداية الحملة |
| تسجيلات اليوم | السجلات منذ منتصف الليل المحلي |
| آخر 24 ساعة / آخر ساعة | السجلات داخل النافذة المذكورة |
| متوسط التسجيل/ساعة | الإجمالي ÷ عدد الساعات منذ أول تسجيل |
| تغيّر سرعة التسجيل | (سرعة النافذة الحالية − السابقة) ÷ السابقة |
| ذروة اليوم / أعلى ساعة | أكبر عدد تسجيلات في يوم/ساعة |
| جودة البيانات | `0.7 × الاكتمال + 0.3 × الصلاحية` من `QUALITY_CHECKS` |

### السرعة والإيقاع
- **الفعلي**: التسجيلات الفعلية لكل ساعة/يوم/أسبوع.
- **المعدل المطلوب**: المستهدف ÷ ساعات الحملة (خط مرجعي متقطع).
- **الإيقاع الحالي**: التسجيلات ÷ الساعات المنقضية.
- **الفجوة**: نسبة انحراف الفعلي عن المطلوب — منها تُولَّد حالة `حرج/انتباه/ممتاز`.

### Timeline (لوحة الحالة)
كل فترة تحمل: `count` · `cumulative` · `expected` (حصة الفترة من المستهدف) ·
`expectedCumulative` · `gap` (الفارق التراكمي).

### التنبيهات
انهيار السرعة، فجوة الإيقاع، معايير تراكمية، جمود البيانات، حجم منخفض،
جودة منخفضة، نافذة الإغلاق — عتباتها كلها في `CONFIG.ALERT_RULES`.

> **ملاحظة**: لوحة «تتبع الهدف» ومؤشراتها (نسبة الإنجاز/المتبقي/التوقع النهائي)
> تمت إزالتها من الواجهة بناءً على طلب التشغيل — محرك السرعة والإيقاع يعمل كما هو.

## الإعدادات المتكررة (`js/config.js`)

```text
DEMO_MODE / API_URL      الوضع ورابط الـ API
REFRESH_INTERVAL         دورة التحديث التلقائي (3 دقائق)
CACHE_TTL                صلاحية الكاش المحلي (دقيقة)
EVENTS / DEFAULT_TARGET  أهداف الإيفنتات (حالياً قيم مؤقتة: 1000/750/500)
ALERT_RULES              عتبات التنبيهات
QUALITY_CHECKS           فحوصات الجودة
```
